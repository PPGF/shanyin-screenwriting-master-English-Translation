# Shanyin Super Screenwriting Master — All-Format Screenwriting Skill

A natural-language-driven screenwriting Agent Skill designed by **@山音**.

Covers the complete screenwriting workflow, from **1–3 minute concept ultra-short films** to **90-minute feature films** and **multi-episode series**, providing an end-to-end solution for character development, outlining, scene planning, and screenplay writing.

## Core Capabilities

### Full-Format Coverage

Seamlessly supports projects ranging from short-form to feature-length productions.

- **Concept Ultra-Short Films:** Supports two directions — *how-to-tell* and *what-if* — for rapidly developing 1–3 minute films.
- **Narrative Short Films:** 5–10 minute polished short films with complete narrative structure, suitable for short-video platforms and short-film competitions.
- **90-Minute Feature Films:** Two creative tracks:
  - Commercial films — strong plot and high-impact entertainment
  - Art films — emotional depth and strong cinematic texture
- **Multi-Episode Series:** Supports seasonal and anthology/episodic structures, including complete series outlines, individual episode scripts, and character development arcs.

## End-to-End Screenwriting

- **Character Design:** Three-dimensional character profiles covering personality, motivations, character arcs, and contrasting traits.
- **Structural Outlining:** Classic narrative models such as the Three-Act Structure and Hero's Journey, combined with genre-specific frameworks for mystery, science fiction, romance, crime, and more.
- **Scene Breakdown:** Shot-level scene planning, including implied visual language, emotional beats, and transition design.
- **Complete Screenplays:** Precise output in standard audiovisual screenplay format, including scene numbers, action descriptions, dialogue, and transitions.

## File Structure

- `Shanyin Super Screenwriting Master.skill` — Core Skill file. Natural-language driven and directly importable into Claude.
- `examples/` *(optional)* — Screenwriting examples in different formats and genres, such as science-fiction concept shorts, art-film feature outlines, and urban drama series scripts.

## How to Use

### 1. Import the Skill

#### AI tools supporting `.skill` or `.zip`

1. Download the `.skill` file from this repository.
2. Open the Claude App or web version.
3. Enter the **Skills** module and select **Import Skill**.
4. Select the local `.skill` file to import and enable the Skill.

#### Other AI tools

For AI tools that do not directly support `.skill`, download the integrated `.md` version, such as the version intended for Gemini.

Drag the `.md` file into the AI tool's conversation interface to begin using it.

### 2. Quick Trigger

Simply use natural language to interact with the Skill. Any relevant natural-language instruction can trigger it.

### 3. Advanced Customization

You can provide Claude with additional details to improve screenplay precision, including:

- **Target audience:** e.g. teenagers, adults, or international markets
- **Style references:** e.g. Wes Anderson-inspired visual texture, Nolan-style suspense, or Miyazaki-inspired warmth
- **Platform requirements:** e.g. short-video pacing, theatrical feature-film runtime, or weekly episodic-series structure
